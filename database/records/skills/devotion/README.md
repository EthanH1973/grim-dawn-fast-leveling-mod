# Grim Dawn OP Devotion

A Grim Dawn devotion database mod with combat-effect values increased to twice their original values.

## Included

- Modified devotion `.dbr` records
- Devotion pet and pet-skill records
- A complete change report in `devotion_2x_summary.md`
- A local Grim Dawn mastery randomizer wheel in `grim-dawn-mastery-wheel/`

## Mastery wheel

Run `grim-dawn-mastery-wheel/START_WHEEL.cmd`, then open `http://localhost:3000/`.
